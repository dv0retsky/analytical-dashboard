## 🚀 About the Project

**СВЧ-Электроника** — учебный/демонстрационный проект интерактивного дашборда для предметной области **сверхвысокочастотной электроники**. Приложение помогает анализировать справочник СВЧ-компонентов и узлов, операции испытаний/поставок, загрузку измерительных стендов, события инженерной команды и статусы технической документации.

Сценарий применения: лаборатория или R&D-подразделение, где ведутся измерения S-параметров, сборка СВЧ-модулей, работа с коаксиальными/волноводными трактами, оформление протоколов испытаний и паспортов изделий.

---

## 🛠 Built With

Проект использует стек для аналитических приложений на Python:

- **Streamlit** — UI и интерактивная навигация по разделам  
- **SQLite** — локальная база данных для хранения демонстрационных данных  
- **SQLAlchemy** — ORM-модели и работа с БД  
- **Pandas** — подготовка и агрегация данных  
- **Matplotlib** — надёжные PNG-графики в интерфейсе и PDF-отчётах  
- **Plotly** — оставлен как совместимая зависимость для расширения интерактивной аналитики  
- **ReportLab** — генерация PDF-отчёта  
- **python-dotenv** — переменные окружения из `.env`  

---

## ✨ Features

- **📈 Dashboard KPI** — объём работ/поставок, количество операций, события команды, подписанные технические документы  
- **📡 Component Analytics** — анализ операций по СВЧ-компонентам, категориям и стендам/участкам  
- **🧩 Components Catalog** — справочник СВЧ-компонентов: активные узлы, пассивные компоненты, волноводы, антенны, материалы и измерительная оснастка  
- **🧪 Test & Supply Operations** — операции испытаний и поставок с датой, стендом/участком, ответственным специалистом, количеством образцов и нормо-стоимостью  
- **👥 Engineering Team Events** — события инженерной команды: ввод в проект, отпуск, больничный, вывод из команды  
- **📄 Technical Documents** — протоколы измерений, карты настройки, акты входного контроля, паспорта изделий и статусы подписания  
- **🗂 PDF Report** — генерация отчёта за выбранный период: графики, таблицы и автоматические текстовые выводы  
- **🎨 Modern Dark UI** — тёмная тема с технологичными зелёными акцентами

## 🗂 Project Structure

```text
analytical-dashboard/
├─ app/
│  ├─ __init__.py
│  ├─ main.py                 # Streamlit UI: разделы, метрики, графики, фильтры
```

## 🗃 Data & Seeding

При запуске приложение автоматически:

- создаёт таблицы, если их нет;
- заполняет демонстрационные данные по СВЧ-компонентам, стендам, операциям испытаний/поставок и техническим документам;
- работает **идемпотентно**: при повторных запусках не дублирует бесконечно строки, а доводит таблицы до целевых минимумов.

Целевые минимумы:

- `products`: ≥ 20 СВЧ-компонентов/изделий
- `sales`: ≥ 320 операций испытаний/поставок
- `hr_events`: ≥ 20 событий инженерной команды
- `hr_documents`: ≥ 20 технических документов

> Внутренние имена таблиц `products`, `sales`, `hr_events`, `hr_documents` оставлены для совместимости с исходной архитектурой проекта. На уровне интерфейса и демонстрационных данных приложение привязано к предметной области СВЧ-электроники.


### Графики и PDF-кириллица

Экранные графики выводятся как PNG, построенные через Matplotlib. Это снижает риск пустых областей графиков из-за несовместимости Streamlit, Plotly и браузерного рендера.

PDF-отчёты используют TTF-шрифт с поддержкой кириллицы. Основной переносимый источник — DejaVu Sans из установленного пакета Matplotlib; если он недоступен, приложение дополнительно проверяет системные шрифты Linux/macOS/Windows. Поэтому кириллица в тексте PDF и подписях графиков должна отображаться без чёрных квадратов.

## ⚡ Getting Started

Чтобы запустить проект локально, убедись, что установлены Python 3.10+ и Git.

### 1️⃣ Clone the repository

```bash
git clone https://github.com/dv0retsky/analytical-dashboard
```

### 2️⃣ Navigate to project folder

```bash
cd analytical-dashboard
```

### 3️⃣ Create virtual environment

Linux / macOS

```bash
python -m venv .venv
source .venv/bin/activate
```

Windows (PowerShell)

```bash
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 4️⃣ Install dependencies

```bash
pip install -r requirements.txt
```

### 5️⃣ Start the app

```bash
streamlit run app/main.py
```

Приложение будет доступно по адресу: `http://localhost:8501`.

## 🖋 Usage Instructions

1. Запусти приложение и перейди по разделам в меню Streamlit:
   - Дашборд
   - Компоненты
   - Испытания и поставки
   - События команды
   - Документы
   - PDF отчёт

2. Для отчёта открой раздел **PDF отчёт**, выбери период и сгенерируй файл.

3. Если нужно пересоздать демонстрационные данные с нуля:

```bash
rm -f data/svch_electronics.db
streamlit run app/main.py
```

## ⚙️ Environment Variables (Optional)

```bash
LOG_LEVEL=INFO
```
